# 인터페이스와 탐색 설계

광석, 레이어, 이동 단계의 값은 `data/ores.json`에 있다. 값은 샘플 기준 초안이다.

## 화면 원칙

- 게임 화면은 글자 기반이다. 광맥, 기계, 지도는 아스키 아트로 그린다.
- 설명 문장은 최대한 없앤다. 기계 상태는 움직임과 색으로 보여 준다.
  - 가동: 불꽃과 연기가 움직이고 진행 바가 찬다.
  - 재료 없음: 불이 꺼진다.
  - 출력 막힘: 화구에 빨간 경고가 뜨고, 막힌 슬롯이 깜빡인다.
- 한글은 아스키 격자 안에 넣지 않는다. 글자 폭이 달라서 정렬이 깨진다. 재료의 전체 이름은 마우스를 올렸을 때 보여 준다.

## 기계 그림

- 기계는 작은 캔버스에 음영 장면을 그리고, 밝기에 따라 글자로 바꿔 6px 글꼴로 출력한다.
- 글자 색은 그림의 색을 따른다. 불꽃, 연기, 계기판은 프레임마다 다시 그린다.
- 외부 스킬이나 라이브러리는 쓰지 않는다.

## 아이템 표기

두 글자 코드에 실제 광물의 색을 입힌다. 코드는 광물의 영문 이름에서 가져왔다. 광물 이름에는 주요 원소를 함께 적는다. 예: `갈철석 (Fe)`, `황동석 (Cu, Fe, S)`.

| 처음 나오는 레이어 | 철 | 구리 | 석탄 |
|---|---|---|---|
| 지표 산화대 | `Lm` 갈철석 | `Ml` 공작석 | `Lg` 갈탄 |
| 얕은 지하 | `Hm` 적철석 | `Cc` 휘동석 | `Bt` 역청탄 |
| 심부 | `Mt` 자철석 | `Cp` 황동석 | `An` 무연탄 |

`data/steam-era.json`의 `iron_ore`, `copper_ore`, `coal`은 이 광석들의 묶음이다. `ores.json`의 `family`가 둘을 잇는다.

레이어가 바뀐다고 광물 종류가 꼭 바뀌지는 않는다. 같은 광물이 여러 레이어에 나올 수 있다. 샘플은 시연을 위해 레이어마다 다른 광물만 배치했다. 레이어별 실제 분포는 아직 정하지 않았다.

## 아이템 도감

화면 위쪽 `도감` 버튼으로 연다. 기계 창과 함께 볼 수 있도록 오른쪽에 붙는 패널이다.

- 아이템을 이름이나 코드로 검색한다.
- 아이템을 고르면 얻는 법과 사용처를 보여 준다. 사용처에는 건설 재료도 포함한다.
- 제작법의 재료를 클릭하면 그 아이템으로 이동하고, `<`로 돌아간다.
- 슬롯에 마우스를 올리고 `R`을 누르면 얻는 법, `U`를 누르면 사용처가 열린다.
- 현재 단계에서 쓰는 아이템만 보여 준다. 뒤 단계 아이템은 숨긴다.

## 인벤토리와 기계 UI

- 플레이어는 인벤토리를 가진다.
- 기계를 클릭하면 기계 슬롯과 인벤토리가 함께 있는 창이 열린다.
- 슬롯 조작은 인벤토리, 창고, 기계에서 같다.

| 조작 | 동작 |
|---|---|
| 좌클릭 | 집기, 놓기, 합치기, 맞바꾸기 |
| 우클릭 | 절반 집기. 들고 있으면 1개 놓기 |
| 휠 아래 | 들고 있으면 1개 놓기. 빈손이면 인벤토리에서 열린 기계로 1개 이동 |
| 휠 위 | 1개 집기. 빈손이면 기계나 창고에서 인벤토리로 1개 이동 |
| `Shift` + 클릭 | 인벤토리와 열린 설비 사이에서 묶음째 이동 |
| `E` | 슬롯 위에서 누르면 음식을 먹는다 |

- 인벤토리와 창고는 `정렬`로 같은 아이템을 합치고 묶는다. 순서는 원자재, 금속 부품, 나머지 가공품이다.
  - 원자재는 `data/ores.json` 순서(철, 구리, 그 외)를 따르고 채집물이 뒤에 온다.
  - 금속 부품은 주괴, 판, 관처럼 형태끼리 모으고, 형태 안에서는 `data/materials.json`의 금속 순서를 따른다.
  - 나머지는 원자재에서 공정 단계가 적은 것부터 놓는다.
- 들고 있는 묶음은 `버리기`로 버린다. 쓰러지면 인벤토리로 돌아온 뒤 손실이 적용된다.
- 기지의 기계는 플레이어가 기지에 있을 때만 열 수 있다. 밖에 있어도 기계는 계속 돌아간다.

## 광맥과 레이어

- 광맥은 월드 시드로 레이어마다 자동 생성한다. 같은 시드는 같은 세계를 만든다.
- 탐사 레벨이 오르면 더 깊은 레이어의 광맥이 보인다.
- 깊은 레이어일수록 광맥이 크다.

## 끝없는 맵

- 맵에는 끝이 없다. 16×16 구역 단위로, 처음 시야에 들어올 때 시드와 구역 좌표로 생성한다. 같은 시드는 같은 세계를 만든다.
- 시작 지역에는 첫 목표를 끝낼 수 있도록 광맥을 보장한다.
- 광맥 크기는 운이다. 기지에서의 거리와 상관없다.
- 지도는 플레이어를 중심으로 움직인다. 기지가 화면 밖이면 거리와 방향을 표시한다.
- 저장에는 탐색한 구역만 들어간다.
- 탐색 범위 제한은 아직 없다. 나중에 정한다.

| 레이어 | 탐사 레벨 | 매장량 | 수단 |
|---|---|---|---|
| 지표 산화대 | 1 | 40~120 | 클릭 채굴 |
| 얕은 지하 | 2 | 1,000~3,000 | 철로 |
| 심부 | 3 | 10,000~30,000 | 자동 운송 |

## 지도 칸

지도 칸은 세 가지다.

| 상태 | 표시 |
|---|---|
| 현재 보이는 곳 | 밝은 칸 |
| 기억하는 곳 | 어두운 칸, 광맥과 지형은 마지막으로 본 대로 표시 |
| 본 적 없는 곳 | 빈 칸 |

- 지도 옆 검색창은 보이는 곳과 기억하는 곳만 찾는다.
- 구역은 16×16칸이고 고유 번호가 있다. 구역 번호로도 찾을 수 있다.
- 고갈된 광맥은 툴팁과 검색 결과에 `(고갈됨)`으로 나온다.
- 산에는 고도 1~3이 있고 `^`, `A`, `M`으로 표시한다. 고도가 높을수록 체력을 많이 쓰고 멀리 보인다.

## 이동과 운송

기술이 오르면 다음 순서로 바뀐다.

1. 도보
2. 이동 속도 소폭 증가
3. 철로 부설, 이동이 크게 빨라짐
4. 철로를 깐 광맥에서 기지 창고로 자동 운송

작은 지표 광맥은 손으로 캐고, 큰 광맥은 철로와 자동 운송을 깔 가치가 있도록 매장량을 잡는다.

샘플에서는 버튼만 누르면 철로와 자동 운송이 열리지만, 실제 게임에서는 별도 요구사항을 충족해야 한다. 구체적인 요구사항은 아직 정하지 않았다.

## 설비 건설

1. 기지에서 설비 이름을 클릭하면 필요 재료와 착수량이 표시된다.
2. `착수`를 누르면 인벤토리와 창고에서 재료가 빠지고 작업이 시작된다.
3. 플레이어가 작업을 수행해 착수량을 채우면 노드가 생긴다.

- 지금은 광맥처럼 클릭으로 착수량을 채운다. 나중에 설비별 퍼즐로 바꿀 수 있다.
- 착수는 한 번에 하나만 진행한다.
- 착수 취소나 설비 철거 시 재료를 전부 돌려준다.
- 작업은 기지에 있을 때만 할 수 있다.
- 철거는 설비 창의 `철거` 버튼을 두 번 눌러야 한다. 노드에는 철거 버튼을 두지 않는다.

## 설비 코드와 목록

- 설비마다 영문 소문자와 숫자로 된 3자리 코드가 붙는다. 예: `0a1`, `q7z`.
- 코드는 설비를 구분할 뿐 종류를 뜻하지 않는다. 철거해도 재사용하지 않는다.
- 상단에는 종류별로 하나씩 표시한다. 종류를 클릭하면 그 건물 목록이 버튼 아래로 펼쳐지고, 고르면 그 건물의 창이 열린다. 바깥을 클릭하거나 Esc를 누르면 닫힌다.


## 연결선과 노드 이름

- 한 방향의 연결은 선 하나로 그리고, 쓰는 채널을 선 위에 표시한다.
- 선 끝의 화살표가 방향이다. 서로 주고받는 연결은 도로처럼 두 차선으로 나란히 그린다.
- 선은 상대 노드를 향한 면에서 나간다.
- 노드의 `+`를 누르고 대상 노드를 클릭하거나, 연결선을 클릭하면 연결 설정 창이 열린다.
- 연결 설정 창에서 채널을 켜거나 끈다. 채널 하나가 포트 하나를 쓴다.
- 지금은 특정 재료만 골라 보낼 수 없다. 필터는 전기시대 이후(S2~S3)에 추가한다.

| 보내는 곳 | 채널 | 내용 |
|---|---|---|
| 창고 | `All` | 필터가 없다. 앞 칸부터 보내다가 받는 쪽이 꽉 차면 다음 재료를 보낸다. 철광석과 석탄을 넣으면 선 하나로 제련로가 돌아간다 |
| 기계 | `Out` | 주 산출물 |
| 기계 | `By` | 부산물 |

- 필터가 없으므로 한 창고에 광석을 섞으면 제련로에도 섞여 들어간다. 나누려면 창고를 따로 둔다.
- 선은 통로일 뿐이다. 보내는 쪽 건물에 동력이 있어야 물건이 움직인다.
- 태엽 동력기는 철판 4, 구리관 2, 착수량 20으로 짓는다. 그림을 클릭하면 태엽이 감겨 힘이 5 쌓이고, 최대 200이다.
- 동력기에서 창고나 기계로 동력 선(`Pw`)을 연결한다. 동력 선도 포트를 1개 쓴다.
- 아이템 1개를 보낼 때마다 힘 1을 쓴다. 힘이 없으면 이동이 멈춘다.
- 감긴 태엽은 쓰지 않아도 10초마다 힘 1이 저절로 풀린다. 가득 찬 태엽은 약 33분이면 빈다.
- 연결 하나에 철판 1, 구리관 1이 든다. 끄거나 철거하면 돌려받는다.
- 창고끼리도 연결할 수 있다.
- 형태를 고르는 기계는 이름에 형태를 함께 표시한다. 예: `성형대 (관) F01`.

## 수동 작업

동력이 없는 작업대는 플레이어가 직접 작업해야 공정이 진행된다. 재료가 차면 초록색 작업 대기 상태가 된다.

| 방식 | 기계 | 조작 |
|---|---|---|
| 자동 | 벽돌 가마, 제련로, 화덕 | 없음 |
| 클릭 | 판금 망치 | 설비 그림을 클릭 |
| 키 입력 | 성형대, 보일러 제작대, 기관 조립대 | 표시된 키(A, S, D, F)를 누름 |

- 입력 1회가 1초 분량의 작업이다. 철판은 4회, 증기기관은 30회다.
- 작업 중 재료를 빼면 진행이 처음으로 돌아간다.

작업 난이도가 실패의 대가를 정한다. 실패는 작업으로 인정되는 입력 중 틀린 것만 뜻한다. 키 입력 기계에서는 A, S, D, F 중 표시되지 않은 키다.

| 기계 | 난이도 |
|---|---|
| 판금 망치 | 1 |
| 성형대 | 2 |
| 보일러 제작대 | 3 |
| 기관 조립대 | 4 |

- 실패할 때마다 진행도를 난이도 × 10% 잃는다.
- 난이도 3 이상은 실패가 쌓이면 재료 1개가 파괴된다. 난이도 3은 4번째마다, 4는 3번째마다다.
- 동력을 연결하면 자동으로 돌아가는 구조는 S2에서 구현한다.

## 테스트 시작

위쪽 `테스트 시작`을 두 번 누르면 시험용 상태로 새로 시작한다. 힘이 가득한 태엽 동력기, 제련로, 재료가 찬 창고가 이미 연결되어 있다. 시험이 끝나면 없앤다.

## 기지 창고

- 자동 운송으로 온 재료는 플레이어 인벤토리가 아니라 기지 창고에 들어간다.
- 창고에 넣을 공간이 없으면 운송이 멈춘다. 공간이 생기면 다시 움직인다.
- 창고는 플레이어가 기지에 있을 때만 열 수 있다.
- 창고는 철 주괴 10개, 착수량 25로 더 지을 수 있다. 건설 재료는 모든 창고에서 차감한다.
- 맨 처음 창고는 철거할 수 없다. 지은 창고는 비워야 철거할 수 있다.

## 가공 기술과 부산물

가공 기술이 오르면 같은 광석에서 더 많은 부산물을 뽑는다. 금속과 슬래그는 항상 나온다.

| 광석 | 가공 Lv2 추가 | 가공 Lv3 추가 |
|---|---|---|
| 갈철석, 적철석 | 규사 | 망가니즈 |
| 자철석 | 티타늄 슬래그 | 바나듐 |
| 공작석 | 탄산가스 | 아연 |
| 휘동석 | 황 | 은 |
| 황동석 | 황 | 금 |

Lv3에서 부산물을 모두 선으로 연결하면 입력 2개, 출력 4개로 포트 6개가 찬다. 기술이 오를수록 얻는 것은 많아지지만, 처리할 라인도 늘어난다.

## 미정 사항

- 기계 UI와 노드 그래프 화면의 관계
- 탐색 행동 자체의 비용과 시간
- 가공 기술이 증기시대 단계 어디에서 오르는지
- 새 부산물의 쓰임새와 `data/steam-era.json` 연결
